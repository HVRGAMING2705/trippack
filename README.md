# TripPack - Travel Packing Checklist App

A fully functional travel packing app that allows users to create trips, build packing lists, and check off items. A working travel app with trips, packing lists, and packing progress.

## Features

- Create trips with destination and dates
- Build packing checklists per trip
- Check off packed items with progress

## Modules

- `trippack_travel_packing_checklist_app`: create_trips_with_destination_and_dates, build_packing_checklists_per_trip, check_off_packed_items_with_progress

## Tech Stack

React, Tailwind CSS, localStorage
